# Mars Grid Demo / CosmoX（デモ）- コンセプト

## 目的
- ユーザーに「宇宙探査・惑星開発に参加している感」を提供するゲームデモを作る
- 実際のクラウドファンディングや現実の土地所有ではない（すべてゲーム内の仮想設定）
- 将来的にSpaceX等の現実世界の宇宙開発情報と接続可能な“ベース”を先に作る

## 世界観（ゲーム内設定）
- 宇宙開発企業「CosmoX（CX）」が惑星探査・開発プロジェクトを進める
- 巨額の開発資金が必要なため、ファンから「仮想トークン（CX）」を募る
- 返礼として惑星表面をグリッド分割した「Grid ID」を配布する
- ユーザーが得る価値は主に「命名権（ファンメイドの名前）」と、集合体としての領土表現

## ゲームの柱
1) グリッド配布（Admin Allocate でランダム配布）
2) 命名（ユーザーが自分の区画に名前を付ける）
3) マーケット取引（出品・購入。出品中はロックされる）
4) マップ視点で“どこを持っているか” “どこが売られているか”を直感的に見せる

## コア体験（UX）
- Mapを起点に、クリック→命名/出品/購入が完結する（コピペ不要）
- どの画面でも Balance（CX残高）と所持区画数が常に見える
- 売り出し中の区画が一目で分かる（価格も分かる）
